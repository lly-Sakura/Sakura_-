线性结构是一种基本的数据结构，主要用于对客观世界中具有前驱和后继的数据关系进行描述
线性结构的特点：数据元素之间呈现一种线性关系，即元素“一个接一个排列”
线性表

线性表常采用顺序存储和链式存储
主要的基本操作是插入，删除和查找等

线性表的定义

$$
一个线性表是n(n>=0)个元素的有限序列，通常表示为：(a_{1},a_{2},\dots,a_{n})
$$

非空线性表的特点如下：
1.存在唯一的一个称作“第一个”的元素
2.存在唯一的一个称作“最后一个”的元素
3.除第一个元素外，序列中的每个元素均只有一个直接前驱
4.除最后一个元素外，序列中的每个元素均只有一个直接后继

线性表的存储结构：顺序存储和链式存储

线性表的顺序存储：
1.线性表的顺序存储是指用一组地址连续的存储单元依次存储线性表中的数据元素，从而使得逻辑上上相邻的两个元素在物理位置上也相邻，如下图：

![](assets/屏幕截图%202026-11-13%20143639.png)

$$
一般地，以LOC(a_{1})表示线性表中的第一个元素的存储位置，在顺序存储结构中，第i个元素(a_{i})的存储位置为：\\
      LOC(a_{i}) = LOC(a_{1}) + (i+1) * L
$$

其中，L是表中每个数据元素所占空间的字节数。根据该计算关系，可随机取表中的任一个元素


采用顺序存储的优点是：可以随机存取表中的元素

缺点是：插入与删除需要移动元素。

插入：在插入元素前要移动元素以挪出空的存储单元，然后再插入元素


$$
在表长为 n的线性表中插入新元素时，共有 (n+1) 个插入位置。在位置 1（元素a_{1}所在位置）插入新元素，表中原有的n个元素都需要移动；在位置 (n+1)（元素a_{n}所在位置之后）插入新元素时不需要移动任何元素。
因此，等概率下（即元素在 \(n+1\) 个位置插入的概率相同时）插入一个新元素需要移动的元素个数期望值 \(E_{insert}\) 为：
E_{insert} = \sum_{i=1}^{n+1} p_i \ast (n - i + 1) = \frac{1}{n+1} \sum_{i=1}^{n+1} (n - i + 1) = \frac{n}{2}
$$

$$
其中，p_{i}表示在表中的位置i插入新元素的概率
$$


删除：删除时同样需要移动元素，以填充被删除的元素空出来的存储单元

$$
在表中为n的线性表中删除元素时，共有n个可以删除的元素，删除元素a_{1}时需要移动n-1个元素
删除元素a_{n}时不需要移动元素，因此，在等概率下删除元素时需要移动的元素个数期望值E_{delete}为
E_{delete} = \sum_{i=1}^{n}q_{i} * (n-i) = \frac{1}{n}\sum_{i=1}^{n}(n-i)=\frac{n-1}{2}
$$


线性表得链式存储
通过指针连接起来得结点存储数据元素，基本的结点结构所示：
![](assets/Pasted%20image%2020261113173608.png)

其中数据域用于存储数据元素的值，指针域则存储当前元素的直接前驱和直接后继的位置信息，指针域中的信息称为指针（或者链）

存储各数据元素的结点的地址并不要求是连续的，因此存储数据元素的同时必须存储元素之间的逻辑关系，另外，结点空间只有在需要的时候才申请，无须事先分配。

结点之间通过指针域构成一个链表，若结点中只有一个指针域，则称为线性链表（或者单链表）
如下图所示：

![](assets/Pasted%20image%2020261113175015.png)

链式存储结构中，只需要一个指针（头指针 head）指向第一个结点就可以顺序地访问到表中的任意一个元素

在代码中的写法：
设线性表中的元素是整型，则单链表结点类型的定义为：(示例使用语言为C语言)
```
typedef struct node{
	int data; //结点的数据域，此处为整型
	struct node* next;  //结点的指针域
}NODE,*LinkList;
```


链式存储插入与删除，其实质都是对相关指针的修改。

链式存储的插入：
在单链表中，若在p所指结点后插入新元素结点（ s所指向结点，已经生成）如下图演示：

![](assets/Pasted%20image%2020261113180105.png)

基本的步骤：
```
s->next = p->next;
p->next = s;
```
即先将p所指结点的后继结点指针赋给s所指结点的指针域，然后将p所指结点的指针域修改为指向s所指结点。

链式存储的删除：
在单链表中删除p所指向结点的后继结点，如下图所示：

![](assets/Pasted%20image%2020261113181004.png)

步骤如下：
```
q = p->next;
p->next = p->next->next;
free(q);
```

即先令临时指针q指向待删除的结点，然后修改p所指结点的指针域为==🔴指向p所指结点的后继的后继结点 ==，从而将b元素所在的结点从链表中删除，最后释放q所指向结点的空间。

在实际应用中，为了简化对链表状态的判定和处理，特别引入一个不存储的数据元素的结点，称为头结点，将其作为链表的第一个结点并令头指针指向该结点

下面是单链表的查找，插入，删除运算的代码实现过程：

单链表的查找运算：
```
LinkList Find_List(LinkList L, int k) {//L为带头结点单链表的头指针
	//在表中查找第k个元素，若找到，返回该元素结点的指针；
	//否则，返回空指针NULL
	LinkList p;
	int i;
	i = 1;
	p = L->next; //初始时，令p指向第一个元素结点，i为计数器
	while (p && i<k) //顺指针链表向后查找，直到p指向第k个元素结点或者p为空指针
	{
		p = p->next;
		i++;
	}
	if (p && i == k) //存在第k个元素且指针p指向该元素结点
	{
		return p;
	}
	return NULL; //第k个元素不存在，返回空指针
} //Find_List
```

单链表的插入运算：
```
int Insert_List(LinkList L, int k, int newElem) { //L为带头结点单链表的头指针
	//将元素newElem插入表中的第k个元素之前，若成功则返回0，否则返回-1
	//该插入操作等同于将元素newElem插入在第k-1个元素之后
	LinkList p, s; //p,s作为临时指针
	if (k==1)
	{
		p = L; //元素newElem要插入到第一个元素之前
	}
	else {
		p = Find_List(L, k - 1); //查找（Find_List)表中的第k-1个元素并令p指向该元素结点
	}

	if (!p) //表中不存在第k-1个元素，不满足运算要求
	{
		return -1;
	}

	s = (node*)malloc(sizeof(node)); //创建新元素的结点空间 s //malloc是给s分配内存空间
	if (!s) return -1; //判断是否分配成功

	s->data = newElem; //newElem元素赋给新的结点空间s的数据域
	s->next = p->next; //p所指向的后继结点赋给s所指向的后继结点
	p->next = s; //将元素newElem插入第k-1个元素之后
	return 0;
}//Insert_List
```

单链表的删除运算：
```
int Delete(LinkList L, int k) { //L为带头结点单链表的头指针
	//删除表中的第k个元素结点，若成功返回0，否则返回-1
	//删除第k个元素相当于令第k-1个元素结点的指针域指向第k+1个元素所在的结点
	LinkList p, q; //p,q为临时指针
	if (k == 1) //删除第一个元素结点
	{
		p = L;
	}
	else {
		p = Find_List(L, k - 1); //查找表（Find_List）中的第k-1个元素并令p指向该元素结点
	}
	if (!p || p->next) //表中不存在第k个元素结点 
	{
		return -1;
	}

	q = p->next; //令q指向第k个元素结点
	p->next = q->next;
	free(q); //释放结点 删除结点
	return 0;
}//Delete_List
```

线性表采用链式存储结构时，不能对数据元素进行随机访问，但是具有插入和删除操作不需要移动元素的优点。
