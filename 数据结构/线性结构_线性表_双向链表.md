双向链表：
双向链表的每个节点都有两个指针，叫前驱(prev)和后继(next)，前驱是指一个节点的指针指向前一个节点，后继是指一个节点的指针指向后一个节点，因此可以从任意一个节点开始，双向遍历整个链表

![](assets/Pasted%20image%2020261124225300.png)

双向链表的节点通常由三个部分组成：数据部分（存储节点的值data)，前驱指针（prev，指向前一个节点的指针），后继（next，指向后一个节点的指针）

注：双向链表需要额外的空间来存储每个节点的前驱指针

特点与操作：

	特点：
		1.双向链表每个节点有两个指针，可以向前或向后遍历
		2.可以任意节点开始向前或向后遍历整个链表
		3.插入和删除节点只需要调整节点的前驱和后继指针即可
		4.可以实现双向循环链表，即首尾节点相连

	常见操作：
		1.遍历链表：可以从头节点开始，按照后继指针依次访问每个节点，或者从尾节点开始，按照前驱指针依次访问每个节点
		2.插入节点：在给定的位置之前或之后插入一个新节点，只需调整前后节点的指针即可
		3.删除节点：删除给定位置上的节点，同样通过调整前后节点的指针来实现
		4.查找节点：可以通过遍历链表来查找特定值或特定位置上的节点

注：使用双向链表时需要注意指针的正确性和更新，以避免出现指针丢失和内存泄漏等问题

定义链表：（使用C++）
```
typedef int LTDataType;

//定义链表
typedef struct ListNode {
    struct ListNode* next; //结点的前驱
    struct ListNode* prev; //结点的后继
    LTDataType data; //存储数据域
}LTNode;
```

创建双向俩表：
```
//创建双向链表
LTNode* BuyListNode(LTDataType x) {
	//计算自定义链表大小
	LTNode* node = (LTNode*)malloc(sizeof(LTNode));
	if (node == NULL)
	{
		//判断是否创建成功
		perror("malloc fail");
		exit(-1);
	}

	//对前节点进行赋值
	node->data = x; //将元素值赋值给新创建的node节点
	node->next = NULL; //节点的后继是NULL
	node->prev = NULL; //节点的前驱是NULL
	return node;
}
```

```
//初始化链表
LTNode* ListInit() {
	LTNode* phead = BuyListNode(-1);
	phead->next = phead; //让头节点的next指针指向头节点
	phead->prev = phead; //头节点的后驱指向头节点
	return phead;
}
```

尾插：

![](assets/Pasted%20image%2020261124225802.png)

```
//尾插
//双向链表要尾插在head（头节点）前插入节点即为尾节点
void ListPushBack(LTNode* phead, LTDataType x) {
	assert(phead); //

	LTNode* new_node = BuyListNode(x); //插入元素x赋值给new_node
	LTNode* tail = phead->prev; //phead->prev(头结点的前驱) 赋值给tail（尾部变量）

	//phead->prev前一个节点指向新节点
	tail->next = new_node;

	//新节点的prev指向上一个节点
	new_node->prev = tail;

	//新节点存放的下一个节点为头节点
	new_node->next = phead;

	//头节点的prev存放新节点，方便尾插
	phead->prev = new_node;
}
```

```
//头插
//头部插入为head（头节点）前一个节点
void ListPushFront(LTNode* phead, LTDataType x) {
	assert(phead);

	LTNode* new_node = BuyListNode(x); //插入元素x赋值给new_node
	LTNode* node = phead->next; //头结点的next赋值给node

	//尾部标号对应示意图中的步骤
	node->prev = new_node; //1
	new_node->next = node; //2
	new_node->prev = phead; //3
	phead->next = new_node; //4
}
```

尾删：即删除head（头节点）的前一个节点
```
//尾删
//尾删即为删除head（头节点）的前一个节点
//不可以先将head（头节点）指向尾删节点NULL，否则有可能造成野指针
//若链表已经被删空，则会出现错误，则应该对删空时进行提醒并终止程序
bool ListEmptyLTNode(LTNode* phead) {
	assert(phead);
	//链表返回只剩头节点（表示链表已经被删空）为真
	//否则为假
	return phead->next == phead; //返回头节点
}

//尾删代码
void ListPopBack(LTNode* phead) {
	assert(phead);

	//判断链表是否被删空：为真即为假，为假即为真
	assert(!ListEmptyLTNode(phead)); //assert(phead->next != phead)

	//head(头节点)的前一个即为尾巴
	LTNode* tail = phead->prev; //head（头节点）前一个节点
	LTNode* tailPrev = tail->prev; //tail的前一个节点

	free(tail); //删除节点

	//重新连接新尾节点
	tailPrev->next = phead;
	phead->prev = tailPrev;
}
```
