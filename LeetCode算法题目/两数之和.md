给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** _`target`_  的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。


![](assets/Pasted%20image%2020261126214056.png)

C语言思路：遍历数组，双循环for，数组遍历，相邻两个数进行相加，直到nums[i] + nums[j] == target ，将两个数的下标返回给result[0] = i，result[1] = j ，如果两个数还没有相加得到target，那么i++,j++进行自增开始下一轮循环

代码演示：

```
#include<stdio.h>
#include<stdlib.h>

int* twoSum(int* nums, int numsSize, int target, int* returnSize) {
	//分配返回数组的内存的内存空间
	int* result = (int*)malloc(sizeof(int) * 2);

	*returnSize = 2;//给内存分配2字节

	//遍历数组
	for (int i = 0;i < numsSize - 1; i++)  //外层循环定义变量i ，i<numsSize - 1,
	{
		for (int j = i + 1;j < numsSize;j++) { //内层循环j = i+1 ，i+1
			if (nums[i] + nums[j] == target) //
			{
				result[0] = i;
				result[1] = j;
				return result;
			}

		}
	}
	return 0;
}

int main() {
	//测试数据
	int nums[] = { 2,11,7,15 };
	int target = 9;
	int numSize = sizeof(nums) / sizeof(nums[0]);
	int returnSize = 0; //用于接收数组的长度

	//调用函数
	int* result = twoSum(nums, numSize, target, &returnSize);

	if (result != NULL)
	{
		printf("找到结果！下标为:%d和%d\n", result[0], result[1]);

		//释放内存
		free(result);
	}
	else
	{
		printf("未找到符合条件的两个数\n");
	}
	return 0;
}
```
