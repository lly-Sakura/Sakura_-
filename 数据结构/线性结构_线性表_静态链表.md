笔记部分：

借助数组来描述线性表的链式存储结构，用数组元素的下标表示元素所在结点的指针

核心思想：**用数组模拟链表**，每个节点存data(数据域) + cur(游标，即下一个节点的数组下标)，用下标0表示空指针NULL。

核心设计：
1.提前申请一块固定大小的数组，作为整个链表的[内存池]，数组的每个元素就是一个链表结点
2.不用真实的内存指针，而是用数组下标来模拟next指针，这个[伪指针]，用cur（游标）来表示
3.数组里的结点分为两类：数据链表（用来存储有效数据）；备用链表（未被使用的结点链表（空闲结点）

静态链表的结构体：
```
//静态链表的最大容量
#define MAXSIZE 100 //定义宏 容量为100

typedef struct {
	int data; //存放有效数据
	int cur;  //游标，存下一个结点的数组下标，替代动态链表的next指针
}SNode,SLinkList[MAXSIZE];
//SLinkList[MAXSIZE]，定义了一个长度为MAXSIZE的数组，每个元素都是SNode类型的结点，也就是我们的整个[内存池]space
```

静态链表的核心：
1.首先，备用链表和数据链表都是在同一个数组里，暂时把整个数组定义成space[]

	核心逻辑：
		space数组就是一块提前申请好的[内存池]，数据链表和备用链表，只是作为这块[内存池]里两个不同角色的结点，两个链表公用同一块数组空间，通过cur的模拟next指针分别串成两条独立的链表
			(1)备用链表：
				作用 ：管理数组里所有未被使用的空闲结点，等价于动态链表的[堆内存]
				头结点：固定为space[0].cur,永远指向备用链表的第一个空闲结点
				结尾：用 cur = 0 表示备用链表为空，无可用空闲结点
				核心操作：Malloc_SL（分配结点）从这里取结点，Free_SL(回收结点)把不用的结点换回来

			(2)数据链表 
				作用：存储有效数据，功能和动态链表完全一致
				头结点：必须单独用一个变量保存（例如 int data_head),绝对不能用space[0].cur
				结尾：用 cur = 0 表示数据链表的结尾
				核心操作：插入，删除，遍历，逻辑与动态链表完全一致
				
**2.cur的本质：用数组下标来模拟next指针，cur变量里存的，永远是下一个结点在数组里的下标，而不是数值本身**
	
	例如：space[1].cur = 3 : 这个表达式的含义是下标为1的结点的下一个结点，是数组里下标为元素3的元素，也就是space[3]
	
	等价于动态链表里的：p->next = q (p指向1号结点，q指向3号结点)
	额外说明：数组下标从0开始计数，因此：
		数组的0号位置 = 下标为0的元素 = space[0]
		数组的3号位置 = 下标为3的元素 = space[0]
		剩下的以此类推。。。

3.备用链表的头结点（也就是0号结点）
	动态链表使用NULL表示空指针
	静态链表使用特殊数字表示“没有下一个结点”
	在这篇笔记里采用space[0].cur 作为备用链表的头结点
	**注意：0号结点不存储有效数据，专门作为备用链表的头结点使用**

3.核心函数：
初始化函数InitSpace_SL：把数组连成备用链表
函数的作用：把整个space数组的所有结点，通过cur指针串成一条备用链表，完成静态链表的初始化，提前准备好完整的空闲结点池。
```
void InitSpace_SL(SLinkList space) {
	//将一维数组space中各分量链成一个备用链表
	space[0].cur; //头指针
	//“0”表示空指针
	for (int i = 0; i < MAXSIZE -1; ++i) 
	{
		space[i].cur = i + 1; //让数组里的第i个结点，指向第i+1个结点，完成链表的串联
		//i=0时：space[0].cur = 1 ➡ 0号结点指向1号结点
		//i=1时：space[1].cur = 2 ➡ 1号结点指向2号结点
		//等等依次类推
		//直到i = MAXSIZE - 2 时：space[MAXSIZE - 2].cur = MAXSIZE - 1 ➡ 倒数第二个结点指向最后一个结点

	}
	space[MAXSIZE - 1].cur = 0; //让数组最后一个结点的cur=0，即指向空指针，作为备用链表的结尾
} //以MAXSIZE =6 为例子，此时的备用链表路：0 ➡ 1 ➡ 2 ➡ 3 ➡ 4 ➡ 5 ➡ 0，数据链表为空
```

结点分配函数Malloc_SL：从备用链表取空闲结点
对应动态链表的malloc函数，作用是从备用链表中取出一个空闲结点，返回它的下标，给数据链表使用
```
//分配结点：若备用空间链表非空，则返回分配的结点下标，否则返回0
int Malloc_SL(SLinkList space) {
	//1.取出备用链表的第一个空闲结点的下标
	int i = space[0].cur;//数组下标为0的下一个结点赋值给i ，i=1

	//2.如果备用链表非空（还有空闲结点） //判断备用链表的状态
	if (space[0].cur)
	{
		//3.把备用链表的头指针，后移到下一个空闲结点
		space[0].cur = space[i].cur;
	}
	//4.返回分配到的结点下标
	return i;
} //Malloc_SL
//逻辑类比 + 逐行拆解
//本质上，是从备用链表的头部删除一个结点，然后头部指针指向下一个备用链表的空闲结点
//1.动态链表：删除头结点 ➡ 先存下头结点的地址 ➡ 把头指针到头结点的next ➡ 返回原头结点地址
//2.静态链表：分配空闲结点 ➡ 先存下第一个空闲结点的下标 i ➡ 把备用链表头指针space[0].cur移到i的下一个结点 ➡ 返回i

//分配过程模拟：（基于上面的初始化状态）
//执行Malloc_SL(space)分配的第一个结点：
//1.i = space[0].cur; ➡ i=1
//2.space[0].cur = 1 ≠ 0，进入if判断
//3.space[0].cur = space[1].cur ➡space[0].cur = 2 //因为空闲结点1，已经被分配出去了，所以头结点指向结点2
//4。返回i=1
//此时备用链表链路：0➡2➡3➡4➡5➡0,数据链表已分配1号结点，可以用data_head = 1记录数据链表的头
```

结点回收函数Free_SL：把不用的结点还回备用链表
对应动态链表中的free函数，作用是把数据链表中不再使用的结点，回收到备用链表中，让它重新变成可分配的空闲结点
```
//回收结点：将下标为k的空闲结点回收到备用链表
void Free_SL(SLinkList space, int k) {
	//1.让被回收的结点k，指向备用链表的第一个结点
	space[k].cur = space[0].cur;
	//2.让备用链表的头指针，指向被回收的结点k
	space[0].cur = k;
}//Free_SL 
//本质上，备用链表的头部插入一个结点
//和动态链表的类比
//动态链表：头插新结点 ➡ 让新结点的next指向原头结点 ➡把头指针指向新结点

//静态链表：回收结点k ➡ 让k的cur（下标）指向原备用链表的第一个结点space[0].cur(头指针指向的第一个结点) ➡ 把备用链表的头指针space[0].cur指向k

//回收过程模拟：（基于上面的分配状态）
//回收1号结点，执行Free_SL(space,1):
//1.space[1].cur = space[0].cur ➡ space[1].cur = 2
//2.space[0].cue = 1 ➡ space[0].cur = 1 (让头结点指向1号结点）
//此时备用链表的状态：0 ➡ 1 ➡ 2 ➡ 3 ➡ 4 ➡ 5 ➡ 0 ，1号结点被回收成功
```

#include<stdlib.h>

#define MAXSIZE 100

typedef struct {
	int data; //存放有效数据
	int cur;  //游标，存下一个结点的数组下标，替代动态链表的next指针

		//直到i = MAXSIZE - 2 时：space[MAXSIZE - 2].cur = MAXSIZE - 1 ➡ 倒数第二个结点指向最后一个结点

	}

		space[0].cur = space[i].cur;

//数据链表：尾插法插入元素
int ListInsert_Tail(SLinkList space, int* data_head, int val) {
	//分配新结点
	 int new_node = Malloc_SL(space); //调用Malloc_SL,对备用链表的结点进行分配，分配到的空闲结点的下标，赋值给new_node
	if (new_node == 0) //判断是否分配成功
	{
		printf("备用链表为空：分配失败！\n");
		return -1; //返回-1.退出程序
	}
	
	//给新结点赋值
	space[new_node].data = val; //val值赋给新结点space[new_node].data
	space[new_node].cur = 0; //新结点作为尾结点，cur = 0

	//如果数据链表为空，新结点作为头结点
	if (*data_head == 0)
	{
		*data_head = new_node;
		return 0;
	}

	//找到数据链表的尾结点
	int p = *data_head; //将数据链表的头结点赋值给p
	while (space[p].cur != 0) //判断当前的结点p的下一个结点的下标是否不等于0
		//如果space[p].cur != 0 ,说明当前结点后面还有结点，它不是最后一个
		//如果space[p].cur == 0 ,说明当前结点后面没有结点了，当前结点的下一个结点为空，那么它就是尾结点
	{	
		p = space[p].cur;  //让p移动到下一个结点，继续往后找
	}
	
	//把结点插入到尾部
	space[p].cur = new_node;
	return 0;
}

//5.遍历数据链表
void ListTraverse(SLinkList space, int data_head) {
	if (data_head == 0)
	{
		printf("数据链表为空！\n");
		return;
	}
	int p = data_head; //把数据链表赋值给p
	printf("数据链表元素：\n");
	while(p!=0) //判断p是否为空
	{
		printf("%d", space[p].data); //有效数据打印出来
		p = space[p].cur; //p移动到下一个结点，继续循环判断
	}
	printf("\n");
}

//主函数：测试静态链表
int main() {
	SLinkList space;
	int data_head = 0; //数据链表的头指针，初始化为空(0)

	//1.初始化静态链表
	InitSpace_SL(space);
	printf("静态链表初始化完成");

	//2.插入元素
	ListInsert_Tail(space, &data_head, 10);
	ListInsert_Tail(space, &data_head, 20);
	ListInsert_Tail(space, &data_head, 30);
	printf("插入元素10，20，30完成\n");

	//3.遍历数据链表
	ListTraverse(space, data_head);

	//4.查看备用链表的头结点
	printf("当前备用链表的第一个空闲结点下标：%d\n", space[0].cur);

	return 0; //退出程序状态

}

以下是静态链表的使用场景：
	
	1.无指针环境
	2.固定内存池：提前申请固定大小的数组，稳定分配内存空间，时间复杂度为O(1)，在嵌入式，单片机等内存受限的场景使用广泛
	3.高性能：在高频分配回收的场景中优势明显
	4.持久化存储：静态链表的数组可以直接写入磁盘，不需要处理指针的序列化问题，在简单的持久化场景中非常实用（持久化存储：把数据从“内存（RAM）”存到“硬盘（磁盘）”上，让数据在程序关闭或断电后依然存在。）
